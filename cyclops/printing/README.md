# 独眼巨人 · 200 mm 静态打印适配版

这是从现有 `../CaveCyclops.blend` 派生的独立版本。原游戏模型、骨骼、贴图和导出物不修改。

本次导出外包尺寸约 **135.5 × 116.0 × 200.0 mm**，95 万三角面，单个连通实体。开放边、非流形边、零面积面均为 0；STL 重新导入通过。实心几何体积约 228.1 cm³，不包含支撑。3MF 单位与索引、STL 二进制结构均已核对。

## 文件

- `CaveCyclops_Print_200mm.blend`：可编辑打印主文件，附中性灰材质和预览场景。
- `CaveCyclops_200mm_SOLID.3mf`：单个实体模型，明确记录毫米单位；不包含打印机配置或支撑。
- `CaveCyclops_200mm_SOLID.stl`：同一模型，坐标按毫米导出。导入切片器后核对总高度 **200 mm，包含底座**。
- `preview_hero.png`、`preview_front.png`、`preview_face.png`：直接渲染实际打印网格；无皮肤贴图或法线贴图掩饰表面。
- `print_validation.json`：封闭性、尺寸、体积、连通性、STL 重新导入及原文件校验信息。
- `make_print_version.py`：制作和验证脚本。

## 此版改动

1. 固定静态姿态，将身体和细节融合为单个连通实体；不包含可动关节。
2. 为原来的单层眼睑增加实体厚度并融合进面部。去掉着色用虹膜薄片，用浅凹瞳孔留下真实的上色定位细节。
3. 加厚皮革腰围、腰带和垂绳；在绳尾背面增加连接，使其成为依附在衣服上的浮雕。
4. 适量加强手指，将原来浮动的指甲嵌入手指或脚趾后融合。
5. 加入一体圆底座，让双脚穿入底座后进行实体融合。
6. 重建鼻孔浅凹，整理法线与三角面，导出 STL / 3MF。

衣边与绳索尺寸是加厚前后参数换算的设计值，不等于已完成整件最小壁厚测量。实际毫米尺寸和网格统计以验证 JSON 为准。

## 打印前仍需做的事

当前没有指定打印机、材料或切片器。本版是 **实心、未生成支撑的几何适配模型**，没有经过物理试打，也不能据此保证任意设备打印成功。

上述网格检查不等于完成全表面最小壁厚、自交和切片逐层验收。

- 在目标切片器核对尺寸、摆放方向、悬空区域和每层轮廓。200 mm 包含底座，但不包括后续支撑或倾斜摆放增加的高度。
- 对下巴、手掌、裙摆、腋下等位置安排支撑，并尽量避开脸部正面。手指附近要保留拆支撑的操作空间。
- 树脂：此版没有空心腔体、排液孔或通气孔。若需要节省树脂，另做经过清洗、排液、通气检查的空心版，不要仅开启空心而不设计孔洞。
- FDM：在切片器选择合适的外墙与填充；模型是封闭实体，并不要求把机器填充率设成 100%。
- 第一轮建议先切出手部与头部做同尺度试打，确认支撑拆除、细节和强度后再打全身。

Blender 文件内部以米建模，显示为毫米；它的高度是 0.2 米。STL 的无单位坐标按毫米写出，3MF 明确声明毫米。若从 Blender 再次自行导出 STL，需确认单位换算，避免得到 0.2 mm 或 200 m 的错误尺寸。

## 复现

使用本机 Blender 执行 `make_print_version.py`。脚本从原始模型重新生成本目录的派生文件；不在原始模型上保存。验证会检查原始模型 SHA-256 未变化。
