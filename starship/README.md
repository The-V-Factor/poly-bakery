# Starship + Super Heavy · 展示模型与打印版

新增：[可分体版本](separable/README.md)，包含 Starship、Super Heavy、底座三件，以及上面级 6 台、助推器 33 台发动机。下面说明对应原来的一体版本。

参考 SpaceX 完整星舰组合外形制作的独立模型：上部 Starship 飞船、下部 Super Heavy 助推器、级间连接、四片襟翼、四片栅格舵及底部发动机群。细节按展示和打印用途简化，不对应某一具体飞行架次的精确工程尺寸。

## 打开模型

- `Starship_FullStack.blend`：展示主文件，不锈钢材质、六边形隔热瓦、开孔栅格舵、33 个简化发动机喷管和展示底座。部件保留分离，便于继续修改。
- `printing/Starship_Print_200mm.blend`：独立的静态打印主文件，一体实体与底座，含中性灰预览场景。
- `printing/Starship_FullStack_200mm.3mf`：打印模型，明确采用毫米单位，不附带打印机参数或支撑。
- `printing/Starship_FullStack_200mm.stl`：同一实体的 STL，按毫米坐标导出。

Blender 主文件打开后默认展示相机视图。数字小键盘 0 切换相机视图，中键旋转查看。展示模型在 `01 | STARSHIP + SUPER HEAVY`，底座在 `02 | DISPLAY BASE`。展示文件还保留隐藏的打印构造网格；正常查看不必显示它。

## 打印适配

成品包含底座，总高 **200 mm**，底座直径约 **66 mm**。

- 打印版四片襟翼按 1.4–1.45 mm 厚度设计，并与箭体融合。
- 栅格舵改为约 1.45 mm 厚的实心背板加浅浮雕网格，根部加入加强结构。
- 尖端加钝；外露细管加粗并嵌入箭体。
- 小发动机喷管简化为与箭体连接的凸起，火箭通过中轴支柱连接底座。
- 不保留展示版独立的细小隔热瓦与标识文字；黑白分区可在打印后上色。

导出检查结果见 `printing/validation.json`：包括连通性、开放边、非流形边、退化面、体积、毫米尺寸及 STL 重新导入检查。

这是 **实心、无支撑的几何适配版**。尚未做目标打印机切片、整件壁厚认证或物理试打。需在切片器设置方向和支撑，尤其检查四片栅格舵下方、襟翼和发动机区域。20 cm 不包括支撑增加的高度；先确认机器的有效成型空间。

FDM 的填充比例由切片器设置，封闭实体不意味着必须使用 100% 填充。若树脂打印需要空心，另行设计排液与通气结构，不要仅打开空心选项。

Blender 内部以米保存，界面显示毫米；模型总高 0.2 米。STL 无单位，但本包的坐标已按毫米写入；3MF 显式记录毫米。自行重新导出时请核对单位。

## 制作

由 `build_starship.py` 在 Blender 5.2.1 中生成，全部几何和材质在本地构建，无外部模型、贴图或账户依赖。脚本重新运行会更新本文件夹中的派生模型和预览，不修改独眼巨人文件。
